# Git-history and data-leak audit — 18 August 2026

## Scope

The visible commit histories and repository trees of `AAstroA/Playground-for-Students` and `AAstroA/vol-surface-risk-lab` were reviewed for credentials, raw licensed data, row-level or dated OptionMetrics panels, downloadable caches, and contract-sensitive derived publications.

## Findings

- No WRDS username, password, MFA artifact, API key, or private `.env` file was found.
- No raw or cleaned WRDS/OptionMetrics observation table was found in tracked `data/raw`, `data/interim`, or `data/processed` paths.
- The checked `sample_outputs/demo` artifacts are generated by the deterministic synthetic generator in `src/spx_risk/data/demo.py`; they are not vendor samples.
- The public teaching repository contained static browser code and aggregate research results, not a database or backend serving licensed rows.
- The research repository did contain a detailed empirical PDF, LaTeX source, generated aggregate fragments, and a WRDS validation note. Their publication status depends on the non-public Bocconi/OptionMetrics agreement and therefore requires institutional confirmation.

## Classification

- Credential incident: **not found**.
- Raw licensed-data disclosure: **not found**.
- Row-level or dated OptionMetrics panel: **not found**.
- Contract-sensitive derived publication: **found and withheld from the current public branch pending review**.

## Containment

The current public-safe branch removes the detailed empirical report, generated empirical report source, and WRDS validation note. Code, synthetic demonstrations, tests, and non-empirical documentation remain public. History rewrite is deferred unless the institution or vendor determines it is required.

This is a technical audit, not a legal opinion; the governing subscription agreement was not available for inspection.
